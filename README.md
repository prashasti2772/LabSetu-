# LabSetu AI

### An Agentic Healthcare & Laboratory Management Platform

LabSetu AI aims to simplify healthcare workflows by connecting
patients, diagnostic laboratories and intelligent AI assistance.

## Vision

Build a unified healthcare platform that makes laboratory
services more accessible, understandable and efficient.

## Key Modules

- Patient Portal
- Laboratory Management
- Appointment Management
- Billing and Payments
- Prescription OCR
- AI-assisted Report Explanation
- Clinova Healthcare Assistant
- Voice-enabled Interaction
- Role-based Access Control

## Technology Stack

- Frontend: React, Vite, JavaScript
- Backend: Node.js, Express
- Database: Supabase, PostgreSQL
- AI Integration: Gemini API
- Document Processing: OCR

## Development Approach

The project is being developed incrementally, with emphasis on:

- Agentic workflow automation
- Patient experience
- Responsible AI assistance
- Secure data handling
- Reliable laboratory operations
